# Security

BUGS! Video Editor runs entirely on your computer and makes no network connections, but files from
other people (videos and photos received through WhatsApp, for example) are still opened by it, so
security problems matter.

## Reporting a problem

Please report security problems **privately**, not in a public issue:

1. Open this repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Describe the problem, the BUGS! version (shown in the ⓘ About screen) and, if you can, a file or
   steps that show it.

You will get a reply as soon as possible. Please give a fix a chance to be released before telling
others about the problem.

## Supported versions

Only the latest release gets fixes. BUGS! is built on Shotcut, MLT and FFmpeg; problems in those
projects are fixed by updating to their newer releases, and are best reported to them as well.
